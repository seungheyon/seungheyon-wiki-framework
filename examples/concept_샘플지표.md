# 응답시간 P95

> 가상의 예시 문서. 실제 데이터가 아니다.

## 정의

가상 서비스 A의 주문 조회 API 응답시간 95 백분위수. "평균은 괜찮은데 느리다는 제보가 있다"는
상황을 설명하기 위해 평균 대신 채택한 지표다.

## 세부

| 시점 | 값 | 비고 |
|---|---|---|
| 2026-02-10 | 820ms | 최초 측정 |
| 2026-04-11 | 240ms | 조회 경로 캐시 도입 후 |

측정은 동일 부하 조건(동시 50, 5분)에서 두 번 모두 수행했다. 두 측정 사이에 인프라 사양 변경은
없었으므로, 차이의 주된 원인은 캐시 도입으로 본다. **다만 트래픽 패턴 차이는 통제하지 못했으므로
"캐시가 전부"라고 단정하지 않는다.**

## 등장 맥락

- 이력서 프로젝트 서술의 성과 문장 근거로 사용.
- [[decision_샘플_캐시전략_20260401]] 의 판단 근거.

## 갱신 이력

- 2026-04-12 — 4월 측정치 추가. 기존 서술("평균 응답시간으로 충분하다")과 **충돌**로 판정해
  지표 자체를 P95로 교체했다. 판정 근거: 기존 서술로는 "평균이 낮으니 체감도 괜찮다"를
  예측하게 되는데, 실제 사용자 제보가 그 예측을 빗나가게 했다.
