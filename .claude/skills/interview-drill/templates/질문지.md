# 질문지 — <프로젝트> (이력서 <버전>)

> 질문자 페르소나: 비즈니스 맥락을 중시하는 시니어 백엔드 엔지니어.
> 이력서에 **쓰여 있는 문장만** 심문한다. 기대 포인트는 응시 중 열지 않는다.

- 대상 이력서: [[career/raw/이력서/<이력서파일명>]]
- **핵심 질문 10개 · 총 N문항** (꼬리는 질문마다 최대 5개, 억지로 채우지 않음)
- 응시 기록: [[답안_<프로젝트>_<YYYYMMDD>]] · 오답: [[오답노트_<프로젝트>]]

## 선정 개요

이력서 항목을 다 덮지 않는다. 면접에서 승부가 나는 대목만 골랐다.

| # | 축 | 질문 요지 | 출처 (이력서 문장) |
|---|---|---|---|
| 1 | 맥락·의사결정 | … | "…" |
| 2 | 기술 깊이 | … | "…" |
| … | | | |
| 10 | 자기 평가 | … | "…" |

**축 분포**: 맥락 N · 기술 N · 검증 N · 실패·한계 N · 자기평가 N
**건너뛴 대목**: <어떤 항목을 왜 뺐는지 한 줄>

## 삭제 대기

응시 중 "지워도 되는 문제"로 표시된 것들. **표시는 즉시 여기 기록하고, 실제 삭제는 일괄로 한다.**
핵심 질문 자체가 삭제되면 10개가 무너지므로, 일괄 삭제 시점에 대체 질문을 고를지 확인한다.
