# 채점 · 오답노트 운영

## 채점 단위

**항목(불릿) 하나가 끝날 때마다** 채점한다. 질문 하나마다 점수를 매기면 흐름이 끊기고,
프로젝트 전체를 다 푼 뒤 채점하면 무엇이 문제였는지 흐려진다.

## 판정 3단계

점수(숫자)를 쓰지 않는다. 이 스킬의 목적은 등수 매기기가 아니라 **못 하는 것 찾기**다.

| 판정 | 기준 |
|---|---|
| **통과** | 질문에 정확히 답했고, 체인 꼬리질문 3개를 끝까지 버텼다 |
| **보완** | 큰 줄기는 맞으나 근거·수치·정의 중 하나가 비었다. 체인 중간에서 멈췄다 |
| **미흡** | 답하지 못했거나, 답이 질문과 어긋났거나, 침묵했다 |

추가로 **사실 정합성**을 매 항목마다 따로 표시한다: `이상 없음` / `불일치 — (내용)`.

## 면접은 대화다 (채점 시 유의)

- **묻지 않은 걸 미리 풀어놓지 않는 것은 감점이 아니다.** 간결히 답해 다음 질문을
  유도하는 것은 좋은 태도다. 짧다는 이유로 `보완`을 주지 않는다.
- 대신 **질문 범위 안의 답이 빠진 것**과 **꼬리질문에 실질을 안 주는 것**("아니요"로 끝냄)은
  그대로 판정에 반영한다.
- 통문장 낭독형 장광설은 `보완` 사유가 된다.

## 오답 원인 분류 (필수)

`보완`·`미흡`에는 반드시 원인 태그를 붙인다. 이 태그가 쌓여야 대시보드가 의미를 갖는다.

| 태그 | 뜻 | 처방 |
|---|---|---|
| `지식공백` | 개념 자체를 모른다 | 학습. 반복되면 `career/concepts/` 페이지로 정리 |
| `설명력` | 알지만 말로 못 푼다 | 정의를 한 문장으로 쓰는 연습, 재응시 |
| `사실불일치` | 이력서·위키와 답변이 어긋난다 | 사실을 먼저 확정하고 이력서/위키 중 한쪽을 고친다 |
| `준비부족` | 오래된 프로젝트라 기억이 안 난다 | 원본 코드·위키를 다시 읽고 답변을 미리 만들어 둔다 |

`사실불일치`는 다른 세 개보다 우선순위가 높다 — 실전에서 그 자리에서 신뢰가 무너지고,
이력서 자체를 고쳐야 할 수도 있으므로 발견 즉시 사용자에게 알린다.

## 오답노트 형식

프로젝트당 **한 파일**을 계속 갱신한다(회차마다 새로 만들지 않는다).
항목마다 다음을 남긴다.

```markdown
### [미해소] 항목 4 — Redis 캐싱 적용 (35ms → 10ms)
- **막힌 질문**: 캐시가 동시에 만료된 순간 수천 건이 몰리면 무슨 일이 생기나요?
- **내 답변**: DB 부하가 커질 것 같다 (원인까지는 짚음) → 해결책에서 멈춤
- **원인**: `지식공백` — Cache Stampede 대응책
- **채워야 할 것**: 단일 갱신 보장(분산 락/single-flight), 만료 시각 지터, 논리적 만료 후
  비동기 갱신 — 세 갈래를 구분해서 말할 수 있을 것
- **1회차** 2026-08-07 미흡
```

해소되면 헤더만 바꾸고 이력을 남긴다.

```markdown
### [해소 2026-08-20, 2회차] 항목 4 — Redis 캐싱 적용 (35ms → 10ms)
```

- **지우지 않는다.** 못 하던 것이 되게 된 기록 자체가 자산이고, 면접에서
  "최근에 새로 공부한 것" 소재로도 쓰인다.
- 같은 항목이 **2회 연속 미흡**이면 헤더에 `집중학습 필요`를 붙이고 사용자에게 알린다.

## 답안 파일 기록 원칙

- **본인이 실제로 쓴 표현을 살려서** 요약한다. 매끄럽게 다듬어 적으면 나중에
  "내가 이때 어떤 말버릇으로 막혔는지"가 사라진다.
- 침묵·"모르겠다"도 그대로 적는다. 그게 데이터다.
- 채점자 코멘트는 답변과 구분되게 적는다(인용 블록 등).

## index 대시보드 갱신

응시가 끝날 때마다 `career/interviews/index.md`를 갱신한다.

1. **시험지 목록** 행: 최근 응시일, 미해소 오답 수
2. **프로젝트별 추이**: 이력서 버전이 달라도 같은 프로젝트 행에 회차를 누적
   (예: `MVPQuest | 260501 1회차 미흡3 → 260805_v4 2회차 미흡1`)
3. **원인 분류 집계**: `지식공백` 상위 주제 3개를 적어 다음 학습 대상을 드러낸다
