# 목표

이 서비스의 모든 앨범 관련 UI는 "진짜 양장본 사진첩을 손으로 넘긴다"는 은유를 기준으로 설계한다.
평면적인 그리드/카드 UI가 아니라 물리적 깊이감과 관성이 느껴지는 3D 인터랙션을 지향한다.

# 핵심 모션 원칙

1. **표지 열림**: 책등(spine)을 회전축으로 하는 3D perspective 회전
   (`transform-style: preserve-3d`, perspective 1000px 이상, 회전 각도에 따라 `box-shadow`와
   그라디언트 오버레이로 입체감 표현)
2. **이징(easing)**: 선형/ease-out 금지. spring 물리 기반 이징 사용
   (예: framer-motion의 `type: "spring"`, stiffness 120~200, damping 20 내외)
3. **순차 등장(stagger)**: 펼쳐진 후 내지 사진들은 50~100ms 간격으로 순차적으로 fade+scale-in
4. **마이크로 인터랙션**: 호버 시 살짝 들리는 elevation, 그림자 강화, 커서 근접 시 미세한
   3D 틸트(parallax tilt)
5. **페이지 전환**: 좌우 넘기기는 종이가 말리는 듯한 곡률 표현
   (`clip-path` 또는 CSS 3D + 그림자 그라데이션으로 근사)

# 기술 스택

- **애니메이션**: Framer Motion(React 환경 기준) 우선, 복잡한 3D는 GSAP + CSS 3D transform 병행
- **상태 관리**: 각 앨범의 열림/닫힘/펼침 단계를 명시적 state로 관리
  (`closed` / `opening` / `open` / `turning`)
- **성능**: `will-change`, `transform`/`opacity` 위주로 애니메이션(레이아웃 리플로우를 유발하는
  속성 애니메이션 금지)

# 상태별 요구 동작

- **목록 페이지 카드**: 호버 시 표지가 살짝 열리는 프리뷰(3~5도 회전)
- **클릭**: 카드가 화면 중앙으로 확대되며 3D 회전으로 완전히 열림 (600~800ms)
- **상세 페이지 진입 후**: 사진들이 스태거로 순차 등장
- **사진 클릭**: 라이트박스로 확대, 배경은 blur 처리
- **뒤로가기**: 열림의 역순 애니메이션(그냥 fade 아웃 금지)

# 일관성 규칙

- 모든 트랜지션 duration은 **300/500/800ms 셋 중 하나만** 사용
- 이징 함수는 프로젝트 전역에서 **하나의 spring 프리셋으로 통일**
- 새로운 컴포넌트를 만들 때도 반드시 위 은유(실물 앨범)에서 벗어나지 않는지 자체 점검
